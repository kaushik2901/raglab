GitLab Handbook RAG Pipeline — API Test Harness

All 11 API endpoints · inputs persisted in localStorage · tab from URL query

GET /health

Ping Postgres + Qdrant, returns service status

GET /artifacts

List available preprocessing output directories

GET /api/v1/eval/runs

Paginated list of evaluation runs

GET /api/v1/eval/runs/{id}

Single eval run detail with per-question results

GET /api/v1/eval/runs/{id}/compare

Compare multiple eval runs side-by-side

POST /api/v1/workflows/preprocess

Trigger clone → preprocess → verify pipeline

POST /api/v1/workflows/index

Trigger parse → chunk → embed → store to Qdrant

POST /api/v1/workflows/eval

Trigger evaluation pipeline

GET /api/v1/workflows/{id}

Get River job status (any type: preprocess/index/eval)

POST /api/v1/chat/chat

RAG question answering — synchronous, full response

POST /api/v1/chat/chat/stream

RAG chat with SSE streaming — token-by-token
